# Setup Scripts

This directory contains environment setup scripts for different shells and platforms.

## ⚠️ Important Notice

**The traditional ROS 2 setup scripts in this directory are DEPRECATED** and should not be used with this pixi-based project. This project uses pixi for environment management, and the ROS 2 environment is automatically configured when you run `pixi shell -e jazzy`.

## Available Scripts

### ❌ DEPRECATED - Traditional ROS Setup Scripts
These scripts are generated by ROS 2's colcon build system and contain hardcoded paths that don't work with pixi environments. **Do not use these scripts.**

- ~~`setup.sh`~~ - **DEPRECATED** - Traditional ROS bash setup
- ~~`setup.zsh`~~ - **DEPRECATED** - Traditional ROS zsh setup
- ~~`setup.bash`~~ - **DEPRECATED** - Traditional ROS alternative bash setup
- ~~`local_setup.sh`~~ - **DEPRECATED** - Traditional ROS local bash setup
- ~~`local_setup.zsh`~~ - **DEPRECATED** - Traditional ROS local zsh setup
- ~~`local_setup.bash`~~ - **DEPRECATED** - Traditional ROS local alternative bash setup

### ✅ Current Setup Method (Pixi)
This project uses pixi for environment management. Use these commands instead:

```bash
# Activate the ROS environment
pixi shell -e jazzy

# Or run commands directly
pixi run -e jazzy <command>
```

### Windows Support
- `setup.ps1` - PowerShell setup script (may still be useful for Windows development)
- `local_setup.ps1` - Local PowerShell setup script

## Dependencies

### ROS 2 Build System Dependencies
The deprecated setup scripts depend on:
- **colcon build system** (for script generation)
- **ROS 2 Jazzy packages** in pixi environment
- **Hardcoded paths** to pixi environment (`/home/rex/gazebo-slam-prototype/.pixi/envs/jazzy`)

### Files Referenced
- `$CONDA_PREFIX/local_setup.sh` (pixi ROS environment setup)
- Project `local_setup.sh` (auto-generated by colcon)

## Migration Guide

### Old Way (DEPRECATED):
```bash
# Don't do this - these scripts have hardcoded paths and won't work
source setup/setup.sh
```

### New Way (RECOMMENDED):
```bash
# Use pixi for environment management
pixi shell -e jazzy

# ROS 2 and all dependencies are automatically available
ros2 --version
```

### Impact of Removal
Removing these scripts will **not break** any functionality since they don't work properly with the pixi environment anyway. The pixi environment provides all necessary ROS 2 setup automatically.
